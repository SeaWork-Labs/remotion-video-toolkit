# Remotion 视频创作

用 React + Remotion 编写代码生成程序化视频，支持动画、字幕、3D、云端渲染。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/remotion-video-toolkit#v1.0.3 --skill remotion-video-toolkit
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill remotion-video-toolkit
```

## 内容

技能正文在 `skills/remotion-video-toolkit/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/remotion-video-toolkit/payload/`，不要反向同步。版本以 git tag 为准。
